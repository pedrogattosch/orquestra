Status em tempo real

Pare de procurar a aba que está esperando você.

Cada terminal mostra o próprio estado. Quando um agente pede aprovação, a aba da sessão ganha um ponto vermelho, o título da janela mostra a contagem e chega uma notificação do sistema.

Recursos

Feito para quem trabalha com vários agentes ao mesmo tempo.

Tela infinita

Cada terminal é um bloco que você arrasta e redimensiona. Zoom com a roda do mouse e “Ver todos” para enquadrar tudo.

Worktrees num clique

Abra o agente numa branch nova e o Orquestra cria o worktree ao lado do projeto. Ao finalizar, só exclui se nada for perdido.

Conexões entre terminais

Setas de comando mostram quem dá as ordens. Setas de dependência mostram quem espera quem.

Anotações à mão

Escreva lembretes direto na tela, com tamanho e cor por trecho, ao lado dos terminais.

Sessões em abas

Separe projetos em sessões, cada uma com o próprio quadro. A aba avisa quando alguém lá dentro precisa de você.

Fechar não para nada

Fechar a janela só a esconde: os agentes continuam rodando. Ao reabrir, as sessões voltam com o mesmo layout.

Maestro

Um terminal que abre os outros.

Dentro de qualquer terminal do Orquestra existe o comando orquestra-abrir. Ele abre um novo terminal na mesma sessão, já ligado por uma seta de comando. O agente que você usa como maestro cria a branch e o worktree e abre o terminal da tarefa sozinho.

# no terminal do maestro
$ orquestra-abrir --pasta ../loja-pix \
    --nome "pagamento pix" --agente claude
maestro pagamento pix

Use o agente que preferir.

Escolha na hora de abrir o terminal. Sem nenhum marcado, abre só o shell.

Os atalhos funcionam fora dos terminais, direto na tela.

  • NNovo terminal
  • CNova conexão entre terminais
  • ANova anotação
  • FVer todos os terminais da sessão
  • EscCancelar conexão ou anotação
Instalar

Pronto em um minuto.

Você precisa de Git, do VS Code (comando code) e dos agentes que quiser usar.

Ubuntu

.deb · amd64
$ sudo apt install ./orquestra_0.1.0_amd64.deb

Aparece no menu de aplicativos e pode ser fixado na dock. Para desinstalar: sudo apt remove orquestra.

Baixar para Ubuntu

Windows

instalador .exe
Orquestra Setup 0.1.0.exe

Rode o instalador. Para desinstalar, use as configurações do Windows.

Baixar para Windows
Só escuta em 127.0.0.1 e recusa pedidos de sites abertos no navegador. Ao desinstalar, projetos, worktrees e branches ficam intactos.
